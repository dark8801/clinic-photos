# 医美门诊客户照片管理系统

基于 Docker 的轻量级客户照片管理应用，专为医美门诊场景设计。

## 功能特点

- 📷 手机/电脑浏览器直接访问，上传照片
- 🎬 支持上传视频文件（MP4、MOV 等），在线预览播放
- 👤 输入客户姓名自动补全，支持多张照片批量上传
- 📅 按日期浏览（年/月/日），查看当天所有客户照片
- 🔍 按客户浏览，查看某客户所有日期的照片
- 🗑 支持删除照片（自动清理空文件夹）
- 📱 响应式设计，手机端体验友好
- 🔒 数据完全存储在 NAS 本地，无需联网

## 目录结构说明

照片按以下结构存储在 NAS 上：

```
/volume1/XYYM/顾客案例/
├── 2025/
│   ├── 05/
│   │   ├── 24/
│   │   │   ├── 张三/
│   │   │   │   ├── 143025_a1b2c3d4.jpg
│   │   │   │   └── 143028_e5f6g7h8.jpg
│   │   │   └── 李四/
│   │   │       └── 150030_i9j0k1l2.png
│   │   └── 25/
│   │       └── ...
│   └── 06/
│       └── ...
└── 2026/
    └── ...
```

照片文件名格式：`时分秒_随机ID.扩展名`

## 部署步骤

### 1. 将项目文件夹复制到 NAS

通过 NAS 文件管理器或 SMB 共享，将 `clinic-photos` 文件夹上传到 NAS：

```
/volume2/docker/clinic-photos/
```

确保 NAS 上已存在照片目标目录（如不存在需手动创建）：
```
/volume1/XYYM/顾客案例/
```

### 2. SSH 登录 NAS 并构建启动

```bash
cd /volume2/docker/clinic-photos
docker compose up -d --build
```

### 3. 访问应用

浏览器打开：`http://NAS的IP地址:5100`

## 端口说明

- 默认端口：**5100**（可在 docker-compose.yml 中修改）
- 如需修改，将 `ports: - "5100:5000"` 中的 `5100` 改为你想要的端口

## 数据备份

- **照片**：`/volume1/XYYM/顾客案例/` 目录（直接拷贝即可备份）
- **数据库**：`/volume2/docker/clinic-photos/data/clinic.db`（客户和元数据信息）

## 注意事项

- 照片文件完全存储在 `/volume1/XYYM/顾客案例/`，Docker 容器删除不影响数据
- 支持 JPG、PNG、GIF、BMP、WebP 图片及 MP4、MOV 等视频格式
- 单张文件最大 2GB
- 系统会自动读取照片的 EXIF 拍摄时间作为分类依据
